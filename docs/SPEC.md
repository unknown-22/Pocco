# Pocco 仕様書（ドラフト v0.1）

> たまごっちを現代風にアレンジした、放置型の電子ペット Web アプリ。
> ステータス: **ドラフト**。末尾の「未決事項」を決めながら更新していく。

---

## 1. コンセプト

スマホ画面の中に小さな部屋があり、ペットがそこで**勝手に生活している**。

- ユーザーが見ていない間も、ペットは寝る・食べる・遊ぶ・散らかす・趣味を見つける・拾ってくる・独り言を言う。
- 開いたときに「留守中の日記（タイムライン）」が残っていて、**閉じている間も生きていた**ことが分かる。
- **死なない**。世話をしないと「弱る」のではなく、**勝手に変な方向へ成長する**。
  - 例: ごはんをあげないと、自分で冷蔵庫を開けるようになり「自立的・食いしん坊」に育つ。
  - 例: 掃除しないと、散らかった部屋に適応して「ずぼら・収集癖」に育つ。
- 世話は「義務」ではなく「育ち方への介入」。放置も一つの育て方。

### デザイン原則

| 原則 | 意味 |
|---|---|
| 罰より変化 | 放置のペナルティは死や病気ではなく、性格・見た目・趣味の変化 |
| 眺めて楽しい | 操作しなくても、部屋を見ているだけで何か起きている |
| 数秒で満足 | 1 回の起動は 30 秒〜2 分で完結できる。ミニゲームも数秒 |
| 日記が主役 | 起動時の一番のご褒美は「留守中に何があったか」を読むこと |

## 2. 前提・非機能要件

| 項目 | 内容 |

| 認証 | なし（ログイン・アカウント不要） |

| データ保存 | ブラウザの IndexedDB（→ 未決事項 Q1） |
| 時間 | 端末のローカル時刻を使用（現実時間と連動） |

## 3. 技術構成（提案）

| 領域 | 採用候補 | 理由 |
|---|---|---|
| ビルド | Vite + TypeScript | 軽量・ローカル起動が速い |
| UI | React（または Preact） | 画面・タブ・モーダルの管理 |
| 状態管理 | Zustand | シンプル |
| 描画 | Canvas 2D（ドット絵スプライト） | 着せ替えのレイヤー合成・写真保存（`canvas.toBlob`）が容易 |
| 永続化 | IndexedDB（Dexie.js） | タイムライン・写真など量が増えるデータに対応 |
| テスト | Vitest | シミュレーションロジックの単体テスト |
| 任意 | vite-plugin-pwa | スマホのホーム画面に追加・オフライン起動 |

**重要な設計方針**: ペットの生活シミュレーション（`sim/`）は UI から独立した**純粋な TypeScript モジュール**にする。
「状態 + 経過時間 + 乱数シード → 新しい状態 + 発生イベント」という関数にしておけば、テストしやすく、将来サーバー側に移すこともできる。

```
src/
  sim/        … シミュレーションエンジン（UI 非依存・純関数）
    engine.ts     時間を進める
    needs.ts      欲求の増減
    brain.ts      行動選択
    events/       イベント定義（データ）
    growth.ts     成長・進化判定
    rng.ts        シード付き乱数
  data/       … 食べ物・アイテム・家具・着せ替え・種族などのマスタ
  store/      … Zustand ストア + IndexedDB 永続化
  render/     … Canvas 描画（部屋・ペット・スプライト）
  ui/         … 画面・コンポーネント
  minigames/  … ミニゲーム
```

## 4. 時間とシミュレーション（最重要）

### 4.1 「閉じている間も生活している」の実現方法

サーバーを持たないため、**アプリを開いた瞬間に留守中の時間をまとめてシミュレーションする（キャッチアップ方式）**。

1. 保存データに `lastSimulatedAt`（最後にシミュレーションした時刻）を持つ。
2. 起動時、`lastSimulatedAt` から現在時刻までを **10 分刻みの tick** で順番に進める。
3. 各 tick で「欲求の変化 → 行動の選択 → イベント抽選」を行い、発生したイベントをタイムラインに記録する。
4. 起動中はリアルタイムで 1 分ごとに tick を進める（見ている間も同じルールで動く）。

### 4.2 決定論的な乱数

- 乱数は `seed = hash(petId, tickの時刻)` から生成する。
- 同じ時間帯を何度計算しても同じ結果になる → リロードで結果をやり直す「リセマラ」ができない。
- 不具合の再現・テストがしやすい。

### 4.3 長時間放置の扱い

| 経過時間 | 扱い |
|---|---|
| 〜72 時間 | 10 分 tick で通常どおりシミュレーション |
| 72 時間〜 | 超過分は 1 時間 tick の簡易シミュレーション（イベントは重要なものだけ記録） |
| 端末時刻が過去に戻った | シミュレーションしない（`lastSimulatedAt` を更新するだけ） |

### 4.4 1 日のリズム

- 現実の時刻に応じて昼/夕方/夜で部屋の照明が変わる。
- 就寝時刻の初期値は 23:00〜7:00。性格（朝型/夜型）で ±2 時間ずれる。
- 就寝中に開くと、寝ている姿が見える。起こすこともできる（機嫌が少し下がる）。

## 5. ペットのパラメータ

### 5.1 欲求（Needs）… 0〜100、時間経過で変化

| 欲求 | 増減 | 高いとき（放置時）に起きること |
|---|---|---|
| 空腹 | 時間で増加 | 自分で冷蔵庫を開ける／拾い食い → 自立度↑・好みが偏る |
| 眠気 | 起きていると増加 | その場で寝落ちする（ソファ・床など） |
| 退屈 | 時間で増加 | 一人遊び・散らかす・趣味を探す → 好奇心↑ |
| さびしさ | 最後の操作からの経過で増加 | 独り言・窓の外を見る → 甘えん坊 or 自立へ分岐 |

※ どの欲求も「死」や「病気」には繋がらない。**ペットは自分でなんとかしようとし、その結果が性格に反映される。**

### 5.2 部屋の状態

| 項目 | 内容 |
|---|---|
| 散らかり度 0〜100 | 遊ぶ・食べる・拾い物で増える。一定以上でゴミ・おもちゃが部屋に描画される |
| 設置家具 | ペットの行動候補を増やす（本棚 → 読書、植木鉢 → 水やり など） |

### 5.3 性格（Personality）… 各軸 -100〜+100、ゆっくり変化

| 軸 | − 側 | + 側 | 主な変化要因 |
|---|---|---|---|
| 活発さ | のんびり | やんちゃ | 遊ぶ頻度、ミニゲーム |
| きれい好き | ずぼら | 几帳面 | 掃除の頻度、散らかり度の平均 |
| 好奇心 | 慎重 | 冒険好き | 散歩・新しいアイテム・家具 |
| 距離感 | 自立 | 甘えん坊 | 世話の頻度、さびしさの放置 |
| 食欲 | 小食 | 食いしん坊 | ごはんの量、自分で食べた回数 |
| 生活リズム | 朝型 | 夜型 | アプリを開く時間帯、夜に起こした回数 |

- 性格は行動の選ばれやすさ・会話の口調・進化先に影響する。
- 1 日あたりの変化量に上限を設け、急に別人にならないようにする。

### 5.4 好み・趣味

- **食の好み**: 食材タグ（甘い/しょっぱい/辛い/野菜/肉/魚/謎）ごとの好感度。食べた回数と反応で形成。
- **趣味**: 条件を満たすと「趣味を見つけた」イベントで獲得（最大 3 つ）。趣味ごとに専用の行動・日記・拾い物が追加される。

| 趣味例 | 獲得条件の例 | 追加される行動 |
|---|---|---|
| ガーデニング | 植木鉢を置く + きれい好き+ | 水やり、芽が出る |
| 読書 | 本棚を置く + のんびり | 本を読む、本の感想を言う |
| 収集 | 散らかり度が高い期間が長い + 好奇心+ | 拾い物を棚に並べる |
| 音楽 | 楽器を拾う | 夜に鼻歌、演奏 |
| 料理 | 自分で冷蔵庫を開けた回数が多い | 謎の料理を作る |
| 天体観測 | 夜型 + 窓際で過ごす時間が長い | 夜に窓の外を見る |

## 6. 成長・進化

| 段階 | 期間の目安（現実時間） | 備考 |
|---|---|---|
| たまご | 〜1 時間 | 画面タップで少し早く孵る |
| ベビー | 〜1 日 | 性格の変化量が大きい時期 |
| こども | 〜3 日 | 趣味を見つけ始める |
| ティーン | 〜7 日 | 性格が固まり始める |
| おとな | 7 日〜 | 進化先が確定 |

- 各段階の切り替わり時に、**性格ベクトルが最も近い見た目（種族）**に進化する。
- 進化先はおとな段階で 12〜16 種類程度を想定。「ちゃんと世話した」系だけでなく、「放置しまくった」系にも魅力的な姿を用意する（例: 冷蔵庫の主、ゴミ山の王、夜更かし詩人）。
- おとな以降の扱い（旅立ち→次の世代、など）は未決事項 Q3。

## 7. 行動 AI（brain）

各 tick でペットの行動を 1 つ選ぶ。**ユーティリティ方式**（候補ごとにスコアを計算し、重み付き抽選）。

```
スコア = 基本値
       × 欲求による補正（空腹が高い → 食べる系↑）
       × 性格による補正（やんちゃ → 遊ぶ系↑）
       × 時間帯による補正（夜 → 寝る↑）
       × 部屋による補正（本棚がある → 読書が候補に入る）
```

行動の例: 寝る / 昼寝 / うろうろ / 一人遊び / 冷蔵庫を開ける / 窓の外を見る / 散らかす / 片付ける（几帳面なときだけ）/ 趣味の行動 / 散歩に出る / 独り言

行動が変わったタイミングや、確率で発生する出来事を **イベント** としてタイムラインに記録する。

## 8. タイムライン（日記）… 目玉機能

### 8.1 表示イメージ

```
┌─────────────────────────┐
│ 🕒 5時間ぶりだね          │ ← 留守中サマリー
│ 寝た 2 回・拾い物 1 個    │
│ 新しい趣味: ガーデニング   │
├─────────────────────────┤
│ 今日                      │
│ 14:32 ベッドの下からコインを見つけた。 🪙 │
│ 13:10 昼寝をしていた。（〜13:50）         │
│ 12:48 冷蔵庫を勝手に開けた。              │
│ 11:03 植木鉢に水をあげた。 🌱             │
│ 昨日                      │
│ 23:41 窓の外をずっと見ていた。            │
└─────────────────────────┘
```

### 8.2 仕様

- 新しい順に表示、日付ごとに区切る。
- 起動時、留守中に新しいエントリがあれば**「留守中サマリー」カード**を最上部に出し、未読エントリを強調表示する。
- 連続する同じ行動はまとめる（例: 「13:10〜13:50 昼寝をしていた」）。
- エントリには重要度（普通 / ちょっと珍しい / 大事件）を持たせ、大事件（進化・趣味獲得・レア拾い物）はアイコンと色で目立たせる。
- 1 日に記録する通常エントリは最大 30 件程度に間引く（重要度の低いものから削る）。
- エントリをタップすると、関連するアイテムや写真に飛べる。
- 保存期間: 無期限（古いものは月ごとに折りたたみ）。

### 8.3 文章テンプレート

イベントはデータとして定義し、テンプレートで文章を生成する。性格によって言い回しを変える。

```ts
{
  id: "fridge_open",
  when: { needs: { hunger: ">= 70" }, userAbsent: true },
  weight: 10,
  cooldownMinutes: 180,
  effects: { hunger: -40, mess: +10, personality: { independence: +2, appetite: +1 } },
  texts: {
    default: ["冷蔵庫を勝手に開けた。", "冷蔵庫の{food}をこっそり食べた。"],
    tidy:    ["冷蔵庫を開けて、ちゃんと閉めた。"],
    messy:   ["冷蔵庫を開けっぱなしにしていた。"],
  },
  importance: "normal",
}
```

## 9. 機能仕様

### 9.1 ごはん

- 食べ物を選んで与える。食べ物は **食材**（そのまま）と **料理**（食材の組み合わせで解放）の 2 種類。
- 各食べ物は味タグ・満腹度・散らかし度を持つ。
- 反応（大好き / ふつう / 苦手）は好みの好感度で決まり、あげるほど好みが強化される。
- 苦手なものも何度もあげると慣れることがある（好み形成の面白さ）。
- 食べ物の入手: 初期所持 + 散歩の拾い物 + 1 日 1 回の「おすそわけ」（ログインボーナス的な補充）。**課金・通貨は無し**（未決事項 Q5）。

### 9.2 遊ぶ（ミニゲーム）

- 1 プレイ 3〜10 秒。ワンタップ〜スワイプで完結するもの。
- 初期案（3 種）:
  1. **キャッチ**: 落ちてくるおやつを左右移動でキャッチ
  2. **かくれんぼ**: 家具の後ろに隠れたペットをタップで当てる
  3. **リズムタップ**: ペットの鼻歌に合わせて 3 回タップ
- 結果に関わらず退屈↓・活発さ↑。成功すると機嫌↑。
- ペットの性格で得意なゲームが変わる（例: のんびり屋はかくれんぼで寝てしまう）。

### 9.3 掃除

- 散らかり度が上がると、部屋にゴミ・食べこぼし・おもちゃが描画される。
- ゴミをタップ（またはスワイプ）で片付ける。まとめて片付ける「掃除機」ボタンも用意。
- 片付けると きれい好き↑ 方向へ少し影響。放置するとずぼら↑、収集癖の趣味が生まれやすくなる。
- 散らかった部屋の中から、たまに**アイテムが見つかる**（掃除のご褒美）。

### 9.4 睡眠

- 現実時刻に連動して自動で寝起きする（4.4 参照）。
- 眠気が高いと昼間でも昼寝する。
- ユーザー操作: 「電気を消す」で寝かしつけ（寝つきが良くなる）、寝ている間にタップすると起きる。
- 就寝中は画面が暗くなり、寝言（会話）が出ることがある。

### 9.5 会話

- 部屋のペットの上に吹き出しで短いコメント（〜20 文字程度）を表示。
- ペットをタップすると話す。放置中は一定間隔で独り言。
- コメントの素材:
  - 現在の欲求（「おなかすいた…」）
  - 直近のタイムライン（「さっきコイン拾ったよ」）
  - 好み・趣味（「トマトはもういい」）
  - 時間帯・曜日・季節（「月曜日だね」）
  - 留守の長さ（「おかえり、長かったね」）
- 性格・成長段階で語尾や言い回しを変える（ベビー期は片言など）。
- すべてローカルのテンプレート生成（LLM 連携は将来の拡張候補）。

### 9.6 散歩

- ユーザーが **一定時間（例: 2 時間）以上アプリを開いていない** と、ペットが自発的に散歩に出ることがある。
- 散歩中の部屋は空っぽで、「おでかけ中」の書き置きが置かれている。
- 30 分〜3 時間で帰宅し、**アイテムを拾ってくる**。
- 拾うアイテムは 好奇心・趣味・時間帯・季節 で抽選。レア度あり。
- 散歩先での出来事もタイムラインに記録（「公園で知らない犬と目が合った」）。
- 手動で「散歩に送り出す」ボタンも検討（未決事項 Q6）。

### 9.7 着せ替え

- スロット: 帽子 / 服 / アクセサリ（顔まわり）/ 手持ち の 4 つ。
- Canvas 上でスプライトを重ねて描画。
- 入手: 拾い物、図鑑の達成報酬、成長の節目。
- ペットの好みがある（嫌いな服を着せると機嫌↓、脱ぎ捨てて部屋が散らかることも）。

### 9.8 部屋

- 変更できる要素: 壁紙 / 床 / 家具（配置スロット制、6〜8 か所）
- 家具はペットの行動候補を増やす（本棚 → 読書、植木鉢 → 水やり、窓 → 外を見る、冷蔵庫 → 勝手に開ける）。
- 家具配置は「スロット制」（自由配置より実装が簡単でスマホで操作しやすい）。

### 9.9 図鑑

| カテゴリ | 登録条件 |
|---|---|
| 種族 | その姿に進化したことがある |
| 食べ物 | 一度でも食べた（好みの反応も記録） |
| アイテム | 拾った・入手した |
| 趣味 | 獲得したことがある |
| イベント | 珍しいイベントを見た（日記の名場面集） |

- 未登録はシルエットとヒントを表示。
- 達成率に応じて着せ替えや家具がもらえる。

### 9.10 写真

- 部屋の画面で「📷」ボタン → 現在の Canvas を PNG で保存。
- 撮影時刻・ペットの状態・直近の日記 1 行をキャプションとして自動付与。
- アルバム画面で一覧表示、端末への保存（ダウンロード / Web Share API）。
- ペットが自分で「自撮り」する低確率イベントもあり（タイムラインから写真へリンク）。

| 🎒 もちもの | 持ち物 | 食べ物・拾い物・着せ替え・家具（ここから装備/設置） |
| 📚 図鑑 | 図鑑・アルバム | 図鑑カテゴリ、写真アルバム |
| ⚙️ 設定 | 設定 | 名前変更、就寝時刻、データのエクスポート/インポート、リセット |

- ステータス表示は数値バーではなく**アイコンと表情中心**（例: お腹の音アイコン）。細かい数値は「ようす」モーダルで確認。

## 11. データモデル（概略）

```ts
interface Pet {
  id: string;
  name: string;
  bornAt: number;               // epoch ms
  stage: "egg" | "baby" | "child" | "teen" | "adult";
  speciesId: string;            // 現在の見た目
  needs: { hunger: number; sleepiness: number; boredom: number; loneliness: number };
  personality: {
    energy: number; tidiness: number; curiosity: number;
    attachment: number; appetite: number; chronotype: number;
  };
  foodPrefs: Record<string, number>;   // 味タグ → 好感度
  hobbies: string[];
  activity: { type: string; since: number; location?: string };
  equipped: { hat?: string; clothes?: string; accessory?: string; hand?: string };
}

interface Room {
  mess: number;
  wallpaperId: string;
  floorId: string;
  furniture: Record<string /*slot*/, string /*furnitureId*/>;
  litter: { id: string; kind: string; x: number; y: number }[];
}

interface TimelineEntry {
  id: string;
  at: number;
  endAt?: number;               // まとめた行動の終了時刻
  eventId: string;
  text: string;
  importance: "normal" | "rare" | "major";
  read: boolean;
  refs?: { itemId?: string; photoId?: string };
}

interface SaveMeta {
  version: number;              // セーブデータのマイグレーション用
  lastSimulatedAt: number;
  lastInteractedAt: number;     // さびしさ・散歩判定に使用
}

// その他: Inventory, Collection(図鑑), Photo(Blob + caption)
```

- セーブデータは JSON でエクスポート/インポートできるようにする（機種変更・バックアップ用）。
